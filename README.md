## Explain The Word

This is a website where you will be given a random word, and you will need to explain what it means. Then your explanation will be rated by the AI, and you will be given a score.

## Live demo

[Try it yourself](https://explain-the-word.netlify.app/)

## Tech stack

- NextJS
- Prisma

## Implemented features

- Explanation evaluation using AI
- Saving results to database
- Recent words on main page
- Viewing results for certain word
- Groq API as main LLM provider
